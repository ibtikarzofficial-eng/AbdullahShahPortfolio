# Abdullah Portfolio — Hero Starter

## Run

```bash
npm install
npm run dev
```

## Replace the portrait

Put your transparent PNG/WebP portrait in `public/portrait.webp` and update this line in `src/components/Hero.jsx`:

```jsx
src="/portrait-placeholder.svg"
```

to:

```jsx
src="/portrait.webp"
```

## Current hero features

- multilingual loading screen
- GSAP loader exit with rounded bottom edge
- full-screen hero reveal
- infinite name marquee
- rotating globe/location badge
- responsive navigation + role copy
- reduced-motion fallback

This is an original implementation inspired by the interaction pattern, not source code copied from the reference site.
